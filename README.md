# usage-bar

Shows your Claude plan usage above the chat box:

`Session 42% (resets in 1h 30m) · Week 17% · Chat context 30%`

- Yellow at 75%, red at 90%; a pop-up warning at 80%, 90% and 100%.
- `/usage-bar` hides or shows it.
- Desktop app and terminal only (not mobile).

## Install

```
/plugin install usage-bar --marketplace OWNER/REPO
```
